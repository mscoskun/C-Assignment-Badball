# C-Assignment-Badball

## About the Project
Badball is an autonomous, football-like simulation developed as a first-year university assignment. The program runs its own simple AI logic where players on the field can pass the ball, defend, and shoot. 

While the core structure was built with AI assistance, I independently developed and integrated custom mechanics, such as the goalkeeper save and clearance system.

## Features
* **Autonomous Gameplay:** AI-controlled players handle passing, defending, and shooting without human intervention.
* **Custom Mechanics:** Includes custom-built event triggers like goalkeeper clearances and dynamic commentator updates.
* **Zero-Player Requirement:** The simulation plays itself. The user only manages the basic execution.

## Controls
The program does not require active gameplay input. You only need to use specific keys to:
* Start the simulation
* Pause
* Stop/Exit

## Built With
* **Language:** C
* **IDE:** Dev-C++
